# MauKue---khalida
MauKue adalah website yang dibuat untuk membantu UMKM atau usaha kue dalam menjual produk dan menerima pesanan secara online. Melalui website ini, pelanggan dapat melihat katalog kue, mengetahui harga dan detail produk, serta memesan kue sesuai keinginan, termasuk kue custom dengan pilihan ukuran, rasa, warna, hiasan, dan tulisan.
